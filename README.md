# hybrid-SRAM-based-Analog-CiM-AI-accelerator
Architected and validated a hybrid SRAM-based Analog Compute-in-Memory (CiM) AI accelerator, delivering scalable 8-bit charge-domain MAC arrays with passive inter-array accumulation, hardware–software co-design, and noise-aware AI training for energy-efficient edge inference using Cadence Virtuoso and PyTorch
